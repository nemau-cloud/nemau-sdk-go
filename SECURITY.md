# Security policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Send the report by
email to security@nemau-cloud.com instead. Reports in French or English are
accepted.

Include what you can of the following:

- the affected version of the SDK (`nemau.Version`);
- a description of the problem and its impact;
- the steps or code needed to reproduce it.

Do not include real credentials, tokens or presigned URLs in the report.

## Disclosure

Nemau Cloud handles reports according to its responsible disclosure policy:
<https://nemau-cloud.com/en/security#responsible-disclosure>.
